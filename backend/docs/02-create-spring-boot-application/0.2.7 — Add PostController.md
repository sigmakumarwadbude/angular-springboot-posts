# 0.2.7 — Add `PostController`

## Goal

Create the REST controller for the Posts API and expose the CRUD operations through HTTP endpoints.

The controller will:

* Define the `/api/posts` base path
* Inject `PostService`
* Handle `GET` requests
* Handle `POST` requests
* Handle `PUT` requests
* Handle `DELETE` requests
* Return appropriate HTTP status codes using `ResponseEntity`

The architecture is:

```text
HTTP Request
     │
     ▼
PostController
     │
     ▼
PostService
     │
     ▼
PostRepository
     │
     ▼
H2 Database
```

> **Architecture rule:** Controller handles HTTP, Service handles application/business logic, Repository handles persistence.

---

## 1. Create `PostController`

Create:

```text
backend/src/main/java/com/example/postsapi/controller/PostController.java
```

Add:

```java
package com.example.postsapi.controller;

import com.example.postsapi.domain.Post;
import com.example.postsapi.service.PostService;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

import java.util.List;

@RestController
@RequestMapping("/api/posts")
public class PostController {

    private final PostService postService;

    public PostController(PostService postService) {
        this.postService = postService;
    }

    @GetMapping
    public List<Post> getAllPosts() {
        return postService.getAllPosts();
    }

    @GetMapping("/{id}")
    public ResponseEntity<Post> getPostById(@PathVariable Long id) {
        return ResponseEntity.ok(postService.getPostById(id));
    }

    @PostMapping
    public ResponseEntity<Post> createPost(@RequestBody Post post) {
        Post createdPost = postService.createPost(post);

        return ResponseEntity
                .status(HttpStatus.CREATED)
                .body(createdPost);
    }

    @PutMapping("/{id}")
    public ResponseEntity<Post> updatePost(
            @PathVariable Long id,
            @RequestBody Post post) {

        Post updatedPost = postService.updatePost(id, post);

        return ResponseEntity.ok(updatedPost);
    }

    @DeleteMapping("/{id}")
    public ResponseEntity<Void> deletePost(@PathVariable Long id) {

        postService.deletePost(id);

        return ResponseEntity.noContent().build();
    }
}
```

---

# 2. Understand `@RestController`

```java
@RestController
public class PostController {
```

`@RestController` tells Spring that this class handles REST requests.

It is effectively a combination of:

```text
@Controller
@ResponseBody
```

Return values from controller methods are automatically serialized into HTTP response bodies.

For example:

```java
@GetMapping
public List<Post> getAllPosts() {
    return postService.getAllPosts();
}
```

Spring converts the `List<Post>` into JSON.

---

# 3. Define the Base API Path

```java
@RequestMapping("/api/posts")
```

This defines the common URL prefix for all methods in the controller.

Therefore:

```java
@GetMapping
```

maps to:

```http
GET /api/posts
```

and:

```java
@GetMapping("/{id}")
```

maps to:

```http
GET /api/posts/{id}
```

# 4. Inject `PostService`

```java
private final PostService postService;

public PostController(PostService postService) {
    this.postService = postService;
}
```

The controller depends on `PostService`.

Spring automatically injects the service through the constructor.

The dependency chain is:

```text
Spring Application Context
          │
          ▼
    PostController
          │
          │ depends on
          ▼
      PostService
          │
          │ depends on
          ▼
    PostRepository
```

### Why constructor injection?

Constructor injection:

* Makes dependencies explicit
* Ensures required dependencies are available
* Allows the field to remain `final`
* Makes unit testing easier

# 5. GET — Retrieve All Posts

```java
@GetMapping
public List<Post> getAllPosts() {
    return postService.getAllPosts();
}
```

Endpoint:

```http
GET /api/posts
```

The controller delegates the operation to:

```java
postService.getAllPosts();
```

The request flow is:

```text
GET /api/posts
      │
      ▼
PostController
      │
      ▼
PostService
      │
      ▼
PostRepository
      │
      ▼
H2
```

If there are no posts:

```json
[]
```

If posts exist:

```json
[
  {
    "id": 1,
    "title": "First Post",
    "body": "Hello Posts API"
  }
]
```

### Why `List<Post>` instead of `ResponseEntity<List<Post>>`?

Spring automatically returns:

```http
200 OK
```

when the controller returns a normal response body.

Therefore this is sufficient:

```java
public List<Post> getAllPosts()
```

There is no need to wrap it in `ResponseEntity` unless we need explicit control over the response status or headers.

# 6. GET — Retrieve Post by ID

```java
@GetMapping("/{id}")
public ResponseEntity<Post> getPostById(@PathVariable Long id) {
    return ResponseEntity.ok(postService.getPostById(id));
}
```

Endpoint:

```http
GET /api/posts/1
```

### `@PathVariable`

The `{id}` in:

```text
/api/posts/{id}
```

is mapped to:

```java
@PathVariable Long id
```

For:

```http
GET /api/posts/10
```

Spring provides:

```text
id = 10
```

to the method.

### `ResponseEntity.ok()`

```java
ResponseEntity.ok(...)
```

returns:

```http
200 OK
```

with the `Post` as the response body.

Example:

```json
{
  "id": 1,
  "title": "First Post",
  "body": "Hello Posts API"
}
```

## `@RequestBody`

```java
@RequestBody Post post
```

tells Spring to deserialize the incoming JSON into a `Post` object.

The flow is:

```text
JSON Request
     │
     ▼
@RequestBody
     │
     ▼
Post object
     │
     ▼
PostService
     │
     ▼
PostRepository
     │
     ▼
H2
```

---

## `201 Created`

After successfully creating the post:

```java
.status(HttpStatus.CREATED)
```

returns:

```http
201 Created
```

Example response:

```json
{
  "id": 1,
  "title": "First Post",
  "body": "Hello Posts API"
}
```

This is preferable to returning `200 OK` because `201 Created` explicitly communicates that a new resource was created.

# 8. PUT — Update a Post

```java
@PutMapping("/{id}")
public ResponseEntity<Post> updatePost(
        @PathVariable Long id,
        @RequestBody Post post) {

    Post updatedPost = postService.updatePost(id, post);

    return ResponseEntity.ok(updatedPost);
}
```

Endpoint:

```http
PUT /api/posts/1
```

Request body:

```json
{
  "title": "Updated Post",
  "body": "Updated content"
}
```

The controller receives:

```text
id = 1
```

and:

```text
post.title = Updated Post
post.body  = Updated content
```

Then delegates to:

```java
postService.updatePost(id, post);
```

A successful update returns:

```http
200 OK
```

with the updated post.
