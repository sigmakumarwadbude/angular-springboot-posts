# 0.2.2 — Create Health Endpoint

## Goal

Create a simple REST endpoint to verify that the **Posts API Spring Boot application is running correctly inside Docker**.

The endpoint will be:

```http
GET /api/health
```

Expected response:

```text
Posts API is running
```

---

## 1. Create the Controller Package

Inside:

```text
backend/src/main/java/com/example/posts/
```

create:

```text
controller/
```

The structure becomes:

```text
backend/
└── src/
    └── main/
        └── java/
            └── com/example/posts/
                ├── PostsApplication.java
                └── controller/
```

---

## 2. Create `HealthController`

Create:

```text
backend/src/main/java/com/example/posts/controller/HealthController.java
```

Add:

```java
package com.example.postsapi.controller;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class HealthController {

    @GetMapping("/api/health")
    public String health() {
        return "Posts API is running";
    }
}
```

---

## 3. Understand the Controller

### `@RestController`

```java
@RestController
```

Marks the class as a Spring REST controller.

Spring automatically creates a bean for this class and uses it to handle HTTP requests.

---

### `@GetMapping`

```java
@GetMapping("/api/health")
```

Maps an HTTP `GET` request to the `health()` method.

Therefore:

```http
GET /api/health
```

calls:

```java
health()
```

---

### Response

```java
return "Posts API is running";
```

The returned string becomes the HTTP response body.

---

## 4. Build the Application

From the `backend` directory:

```bash
docker build -t posts-api .
```

Expected result:

```text
Successfully built ...
Successfully tagged posts-api:latest
```

---

## 5. Run the Application

```bash
docker run --rm -p 8080:8080 posts-api
```

Wait until Spring Boot reports:

```text
Started PostsApplication
```

---

## 6. Test the Health Endpoint

Open:

```text
http://localhost:8080/api/health
```

Or use:

```bash
curl http://localhost:8080/api/health
```

Expected response:

```text
Posts API is running
```

---

## 7. Request Flow

The request travels through Spring Boot as follows:

```text
HTTP Client
     │
     │ GET /api/health
     ▼
Spring Boot
     │
     ▼
HealthController
     │
     ▼
health()
     │
     ▼
"Posts API is running"
```
