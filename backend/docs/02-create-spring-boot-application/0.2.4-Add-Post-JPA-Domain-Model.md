# 0.2.3 — H2 Database Configuration

## Goal

Configure the Posts API application for **Docker-based development** using an **H2 in-memory database**.

In this step we will:

* Set the application name to `posts-api`
* Configure server port `8080`
* Configure an H2 in-memory database named `postsdb`
* Configure the H2 JDBC driver and credentials
* Configure the Hibernate H2 dialect
* Enable automatic schema updates for development
* Enable formatted SQL logging
* Disable Open Session in View for REST API development
* Enable the H2 web console at `/h2-console`

> **Note:** We will use `application.properties`, not YAML.

---

## 1. Open Application Configuration

The Spring Initializr project contains:

```text
backend/
└── src/
    └── main/
        └── resources/
            └── application.properties
```

Open:

```text
src/main/resources/application.properties
```

---

## 2. Configure the Application

Replace the contents of `application.properties` with:

```properties
# Application
spring.application.name=posts-api

# Server
server.port=8080

# H2 Database
spring.datasource.url=jdbc:h2:mem:postsdb
spring.datasource.driver-class-name=org.h2.Driver
spring.datasource.username=sa
spring.datasource.password=

# Hibernate / JPA
spring.jpa.database-platform=org.hibernate.dialect.H2Dialect
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
spring.jpa.properties.hibernate.format_sql=true

# Disable Open Session in View
spring.jpa.open-in-view=false

# H2 Web Console
spring.h2.console.enabled=true
spring.h2.console.settings.web-allow-others=true
spring.h2.console.path=/h2-console
```

```properties
spring.application.name=posts-api
```

Sets the Spring Boot application name.

```text
posts-api
```

## 4. Configure Server Port

```properties
server.port=8080
```

Spring Boot will listen on:

```text
http://localhost:8080
```

```text
Host                  Container
```

## 5. Configure H2 Database

### JDBC URL

```properties
spring.datasource.url=jdbc:h2:mem:postsdb
```

This creates an **in-memory H2 database** named:

```text
postsdb
```

The database exists only while the application is running.

```text
Spring Boot
     │
     ▼
H2
 └── postsdb
```

> Because this is an in-memory database, restarting the Docker container clears the database contents.

---

### H2 JDBC Driver

```properties
spring.datasource.driver-class-name=org.h2.Driver
```

Specifies the JDBC driver used to connect to H2.

---

### Database Username

```properties
spring.datasource.username=sa
```

H2's default development username is:

```text
sa
```

---

### Database Password

```properties
spring.datasource.password=
```

The password is intentionally empty for this development database.

---

## 6. Configure Hibernate H2 Dialect

```properties
spring.jpa.database-platform=org.hibernate.dialect.H2Dialect
```

This tells Hibernate that the application is using H2.

Hibernate uses the dialect to generate database-specific SQL.

```text
JPA
 │
 ▼
Hibernate
 │
 ▼
H2Dialect
 │
 ▼
H2 SQL
```

---

## 7. Enable Automatic Schema Updates

```properties
spring.jpa.hibernate.ddl-auto=update
```

During development, Hibernate automatically updates the database schema based on JPA entities.

For example, when we later create:

```java
@Entity
public class Post {
    ...
}
```

Hibernate can create/update the corresponding database table.

> `update` is convenient for development. Production applications generally require a controlled database migration strategy such as Flyway or Liquibase.

---

## 8. Enable SQL Logging

```properties
spring.jpa.show-sql=true
```

Displays SQL generated by Hibernate in the application logs.

For example:

```text
Hibernate:
    select
        p1_0.id,
        p1_0.body,
        p1_0.title
    from
        post p1_0
```

---

## 9. Enable Formatted SQL

```properties
spring.jpa.properties.hibernate.format_sql=true
```

Formats generated SQL to make it easier to read in Docker logs.

Without formatting, SQL may appear as a single line.

With formatting:

```text
select
    p1_0.id,
    p1_0.body,
    p1_0.title
from
    post p1_0
```

---

## 10. Disable Open Session in View

```properties
spring.jpa.open-in-view=false
```

Disables Spring's Open Session in View pattern.

For a REST API, this encourages database access to happen inside the appropriate service/transaction boundary rather than allowing lazy database access to continue during HTTP response rendering.

This gives us a cleaner architecture:

```text
Controller
    ↓
Service
    ↓
Repository
    ↓
Database
```

rather than allowing database access to leak into the controller/API response layer.

## 11. Enable H2 Web Console

Enable the H2 console:

```properties
spring.h2.console.enabled=true
```

Set the console path:

```properties
spring.h2.console.path=/h2-console
```

The H2 console will be available at:

```text
http://localhost:8080/h2-console
```
