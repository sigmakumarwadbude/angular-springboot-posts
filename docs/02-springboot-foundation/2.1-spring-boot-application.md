# 2.1 Spring Boot application

## Goal

Create the initial Spring Boot application structure for the posts backend.

## Steps

### 2.1.1 Open Spring Initializr

Go to [https://start.spring.io](https://start.spring.io) in your browser.

Spring Initializr is the fastest way to generate a new Spring Boot project with the right base structure.

### 2.1.2 Configure the project

Set the project metadata so the generated application matches this repository.

- **Project:** Maven
- **Language:** Java
- **Spring Boot:** Use the current stable release for your setup
- **Group:** `com.example`
- **Artifact:** `posts-api`
- **Name:** `posts-api`
- **Package name:** `com.example.postsapi`
- **Packaging:** Jar
- **Java:** 21

These values determine the package structure and build output for the application.

### 2.1.3 Add dependencies

Add the dependencies needed for the first version of the API.

- **Spring Web** for REST endpoints
- **Spring Data JPA** for persistence
- **H2 Database** for local in-memory storage
- **Spring Boot DevTools** for faster development feedback
- **Validation** for request validation

This set gives us a clean starting point for the API, database access, and basic validation.

### 2.1.4 Generate the project

Click **Generate** to download the Spring Boot project as a ZIP file.

After the download finishes, extract the archive to a working folder on your machine.

### 2.1.5 Copy files to the project

Move the generated Spring Boot files into the `posts-api` directory inside this repository.

Make sure the project structure includes:

- `pom.xml`
- `src/main/java`
- `src/main/resources`
- `src/test/java`

If you already have a project folder in place, merge the generated files carefully instead of overwriting unrelated work.

### 2.1.6 Open the project

Open the project in your IDE, such as IntelliJ IDEA, VS Code, or Eclipse.

Verify that the project is recognized as a Maven application and that dependencies are resolved successfully.

### 2.1.7 Understand the main class

Spring Boot creates an application entry point in the main Java package.

The main class usually looks like this:

```java
@SpringBootApplication
public class PostsApiApplication {

    public static void main(String[] args) {
        SpringApplication.run(PostsApiApplication.class, args);
    }
}
```

What it does:

- `@SpringBootApplication` marks the class as the application bootstrap point
- `main` starts the Spring Boot runtime
- `SpringApplication.run(...)` launches the embedded server and application context

This class is the starting point for all future controllers, services, and repositories in the project.
