# 2.2 Java 21 + Docker

## Goal

Run the backend on Java 21 and prepare a Docker-based development/runtime setup.

## Steps

### 2.2.1 Verify Java 21

Make sure Java 21 is installed on your machine and available on the command line.

Run:

```bash
java -version
```

The output should show a Java 21 runtime.

### 2.2.2 Configure the project for Java 21

Check the build configuration so the project compiles against Java 21.

- Set the Java source and target version to `21`
- Make sure the IDE uses the same JDK
- Confirm Maven or Gradle is aligned with Java 21

This avoids version mismatches between local development and the build pipeline.

### 2.2.3 Add Docker support

Create a Docker setup for running the application in a container.

Typical Docker files include:

- `Dockerfile` for building the app image
- `docker-compose.yml` if you want to run the app together with supporting services

This makes the project easier to run in a consistent environment.

### 2.2.4 Build the application image

Use Docker to package the Spring Boot application into an image.

The image should:

- Run on a Java 21 base image
- Copy the built application artifact into the container
- Expose the application port

This keeps the runtime environment close to production.

### 2.2.5 Run the container locally

Start the container and confirm the application launches successfully.

Check that:

- The app starts without errors
- The expected port is exposed
- The health endpoint responds from inside the container

### 2.2.6 Keep the setup reproducible

Document the commands needed to build and run the app so anyone on the team can use the same workflow.

That usually means:

- A single build command
- A single run command
- Clear notes about required ports and environment variables
