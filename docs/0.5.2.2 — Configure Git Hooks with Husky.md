# 0.5.2.2 — Configure Git Hooks with Husky

## Objective

Configure **Husky at the Git repository root** so that every local commit validates the Angular application before the commit is created.

This section also establishes the root `.gitignore` for the combined Spring Boot + Angular project.

The pre-commit workflow will run:

```text
git commit
    │
    ▼
Husky
    │
    ├── Angular lint
    │
    └── Angular unit tests
            │
        ┌───┴───┐
       PASS    FAIL
        │        │
     Commit    Reject
```

### Important

Do **not** add these to `.gitignore`:

```text

package.json
```

These files are part of the project and must be committed.

Check the Git status:

```bash
git status
```

If `frontend/node_modules` exists, verify that Git ignores it:

```bash
git check-ignore -v frontend/node_modules
```

You should get a result showing that the path is ignored by `.gitignore`.

You can also check:

```bash

```

# 4. Remove Incorrect Frontend Husky Configuration

If Husky was previously initialized inside `frontend`, remove it:

```bash
rm -rf frontend/.husky
```

If Husky was installed inside the Angular project, remove it:

```bash
cd frontend
```

Then:

```bash
MSYS_NO_PATHCONV=1 docker run --rm -it \
  -v "$(pwd):/workspace" \
  -w /workspace \
  node:22-alpine \
  npm uninstall husky
```

Return to the project root:

```bash
cd ..
```

# 5. Create Root `package.json`

Husky belongs to the Git repository, so its package configuration should be at the repository root.

If a root `package.json` already exists, keep it.

Otherwise:

```bash
npm init -y
```

The structure becomes:

```text
angular-springboot-posts/
├── package.json              ← repository tooling
├── package-lock.json
├── .gitignore
├── .husky/
├── backend/
└── frontend/
    └── package.json          ← Angular dependencies
```

# 6. Install Husky at the Repository Root

From the project root:

```bash
MSYS_NO_PATHCONV=1 docker run --rm -it \
  -v "$(pwd):/workspace" \
  -w /workspace \
  node:22-alpine \
  npm install --save-dev husky
```

This updates:

```text
package.json
package-lock.json
```

---

# 7. Configure the `prepare` Script

The root `package.json` should contain:

```json
{
  "scripts": {
    "prepare": "husky"
  }
}
```

Preserve any existing scripts.

For example:

```json
{
  "name": "angular-springboot-posts",
  "private": true,
  "scripts": {
    "prepare": "husky"
  },
  "devDependencies": {
    "husky": "^9.0.0"
  }
}
```

The actual Husky version is determined by the installed package.

# 9. Configure the Pre-Commit Hook

Open:

```text
.husky/pre-commit
```

Use:

```bash
MSYS_NO_PATHCONV=1 docker run --rm \
  -v "$(pwd)/frontend:/workspace" \
  -w /workspace \
  node:22-alpine \
  sh -c "npm run lint && npm run test:ci"
```

The hook runs the Angular validation inside Docker.

---

# 10. Configure Angular Test Script

Open:

```text
frontend/package.json
```

Ensure the scripts include:

```json
{
  "scripts": {
    "start": "ng serve",
    "build": "ng build",
    "test": "ng test",
    "test:ci": "ng test --watch=false",
    "lint": "ng lint"
  }
}
```

The important CI/pre-commit script is:

```json
"test:ci": "ng test --watch=false"
```

# 14. Verify Failure Protection

Temporarily introduce an ESLint violation.

Then:

```bash
git add .
git commit -m "test: verify lint protection"
```

The pre-commit hook should fail.

The commit should not be created.

After fixing the problem:

```bash
git add .
git commit -m "fix: resolve lint issue"
```

The commit should succeed.
